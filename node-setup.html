LUMA Node Setup

Run a supporting node for the network: it syncs and relays the ledger, serves its own RPC and WebSocket, and does not validate. Fill this in, then copy the one command into a terminal.

1. Network

2. Connect to the network

The node can only join if the operator's peer port is reachable from your machine and you have the operator's validator list and node image. Ask the operator for all three.

4. Run it

Paste this into a terminal (Mac, Linux, or WSL). It writes the config and starts the node in Docker:



First time only, load the image the operator sent you: docker load < luma-node-image.tar. Check progress with docker logs -f NAME. When it reports full, the node is synced; your WebSocket is ws://localhost:PORT.
